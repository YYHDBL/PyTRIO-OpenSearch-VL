## 16题开发验证集

每题4次采样，共64条回答全部生成。答案准确性完整统计为SFT38/64、RL36/64；有终端答案时读取已保存的accuracy裁判结果，无终端答案时按原规则记0。rl-0115-r1的accuracy已判对，缺失的是被GLM内容审核HTTP400拒绝的搜索质量query评分，原样重试仍失败，故组合奖励只有63条、complete=false。核对没有新增请求或修改评分，见[三阶段完整比较](training-stage-comparison.md)。

| 相同63条回答 | SFT | RL |
| --- | ---: | ---: |
| 答案正确数 | 38 / 63 | 35 / 63 |
| 平均格式奖励 | 0.5493 | 0.6703 |
| 平均搜索质量奖励 | 0.5683 | 0.5444 |
| 平均组合奖励 | 0.3532 | 0.4190 |

答案准确率仍使用完整64条：SFT38、RL36。63条完整组合奖励样本中，5条由错变对、7条由对变错；答案分母不能沿用组合奖励表的63条口径。

表中63条是完整奖励齐全的配对口径；答案准确性应优先报告全部64条。组合奖励上升主要伴随格式奖励上升，答案通过率没有提高；不能把奖励上升直接写成解题能力提升。验证题未参与RL参数更新，但此前使用SFT诊断观察过难度，属于开发集，不替代独立benchmark。
