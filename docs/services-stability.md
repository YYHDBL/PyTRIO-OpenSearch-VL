## 百炼修复及错误恢复

原失败图片配原参数复现了 max_output_tokens 导致的 incomplete，当时实际 image_search 已完成。原正式请求没有原始回包，复现不能还原其全部细节或替代账单。

当前辅助调用关闭额外思考、temperature=0、输出上限 4096，只要求执行一次检索后回复 OK。应用读取完整 image_search_call 原始输出，不将 OK 当搜索结果。完整响应与工具完成状态仍严格校验，没有放宽规则接收任意未完成结果。图搜读取等待上限现为 240 秒、连接上限 10 秒；本批在此前更严格的 120 秒读取上限下通过。

收到 HTTP 响应即保存完整字节、状态码和允许的请求 ID 响应头，文件权限 600，不保存认证头。百炼在最终结构校验前记录服务端 usage，因此 incomplete 也不会漏掉已执行的检索。GLM 也保存原始响应和不确定提交。

只有确定未发送的连接失败才安全重试；DeepSeek 对明确返回的 408/429/5xx 依官方失败计费规则有限重试。发送后读取超时保留 pending，不自动重传。OCR 持有任务 ID 后只恢复查询，确定连接未建立时才解除未发送标记。

目标页面明确返回 403/404 时，文字工具可注明来源限制后使用搜索返回的摘要片段；连接错误及不确定提交暂停，不静默降级。网页内容本身是否正确、是否覆盖全部海外网站，不由连通性检查保证。

## 数据与使用边界

[DeepSeek API](https://api-docs.deepseek.com/zh-cn/guides/search/) 的 query 最长 128 字符，超长明确反馈，不截断或自动改写。Google 的 hl 参数不再起作用，语言由原 query 决定。现有七工具 SFT 中 545 次文字查询最长 122 字符，均兼容；200 题评测、128 道 RL 题和 512 条 SFT 哈希核验均未变化。

旧正式请求 pending，以及诊断阶段一次 120 秒 ReadTimeout 的 pending 仍保留；本次使用独立新请求设置，没有清掉旧标记或把未知费用算作零。各类用量是客户端证据，实际账单需另行核对。

这是小批量可用性和恢复能力验收，未做长时间负载验证。图搜仍慢，部分网页可能拒绝抓取；工具可用不代表 4B 模型能在 16k 上下文内完成所有任务。用户要求先稳定服务再考虑评测，因此新 benchmark 和定时任务均保持暂停。
